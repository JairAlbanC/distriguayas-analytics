# \# DistriGuayas Analytics

# 

# Proyecto de análisis de datos para una distribuidora de consumo masivo en Guayaquil (caso simulado). Parte de datos desordenados en Excel y llega a un dashboard y un análisis predictivo.

# 

# \## Herramientas

# \- Excel (limpieza de datos)

# \- PostgreSQL + DBeaver (base de datos y SQL)

# \- Power BI (dashboards)

# \- Python / Jupyter (pandas, análisis)

# 

# \## Estructura

# \- `data\_raw/`: datos originales sin modificar

# \- `data\_clean/`: datos limpios

# \- `sql/`: scripts SQL

# \- `notebooks/`: análisis en Python

# \- `dashboards/`: archivos de Power BI

# \- `docs/`: documentación

#
